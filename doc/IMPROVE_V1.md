## 1. 视觉/拟物化（最严重）

### 1.1 档案馆登录页 (archive.html)
- ❌ 当前：纯米黄色 + 简单表单
- ✅ 应该：仿 2003 年档案馆 VFP/Access 风格
  - 顶部模仿 Windows Server 2003 蓝条标题 + 应用程序图标
  - 表单字段：3D 凸起 + 灰底 + 微软日历控件样式
  - 底部状态栏：「当前用户: 0  当前时间: 14:23  数据库: 1980-2009」实时数字
  - 错误提示：Windows 经典黄底感叹号弹出框
  - **窗口边框**用 Win9x 灰色凸起 + 内嵌「正在连接到档案馆服务器...」动画

### 1.2 检索结果页 (search.html)
- ❌ 当前：扁平卡片
- ✅ 应该：Access 风格数据表
  - 每个频道用**伪表格**：编号 + 标题 + 时间 + 操作按钮
  - 表格有行高交替底色（zebra）
  - 「档案销毁记录」用**红底红字 + 印章覆盖**
  - 「工作人员提示」用**黄色便签纸 + 手写体**

### 1.3 6 个频道页
- ❌ 当前：白底卡片 + 黑字
- ✅ 应该：每个频道**独立的视觉风格**对应 2003 不同系统
  | 频道 | 风格 | 关键元素 |
  |---|---|---|
  | c1 黑河日报 | 报纸扫描 + OCR 错字 | 报纸边框、印章、曝光噪点、纸纤维 |
  | c2 户籍档案 | 公安内网 (Linux+Firefox) | 蓝条 + 表格 + 浮水印「机密」+ 涂黑遮盖 |
  | c3 第 135 厂 | 企业 MIS (DOS) | 蓝色字符界面 + 方框 + 工资条单据 |
  | c4 奶奶家遗物 | 老 Kindle 墨水屏 | 米色 + 字体灰 + 翻页动画 + 慢加载 |
  | c5 QQ 群 | 2009 QQ 客户端 | 蓝头 + 头像 emoji + 气泡 + 表情包 + 抖窗 |
  | c6 寻人公告 | 公安协查函 | 红头 + 印章 + 「机密」+ 楷体印刷 |

### 1.4 整体 UI 框架（顶部 / 底部 / 状态栏）
- ❌ 当前：普通导航
- ✅ 应该：模拟 2003 Windows 桌面 + 任务栏
  - 顶部：仿「Internet Explorer 6」窗口边框
  - 底部：Windows XP 任务栏 + 开始按钮 + 系统时间 + 音量
  - 标题栏：URL 地址栏（只读）+ 前进后退
  - 状态栏：「档案库: 127.0.0.1 | 已加载 6/6 | 加密传输 ✓」

## 2. 内容/细节（核心差距）

### 2.1 渠道 1：黑河日报
- ❌ 当前：7 条新闻
- ✅ 应该：**30+ 条新闻**，跨 1989-2009 整个 20 年
  - 1990-1991：爷爷厂里运动会、捐款
  - 1995：周德厚失踪的当地新闻 + 民生新闻
  - 1997：搬迁新闻
  - 2001-2002：奶奶、爷爷亡故的讣告
  - 2003：北山屯拆迁新闻
  - 2005-2009：大学生相关
  - **每条都带手写便签/涂改/批注** = 拟真

### 2.2 渠道 2：户籍档案
- ❌ 当前：5 条记录
- ✅ 应该：**20+ 条记录**
  - 1955-08-22 出生
  - 1955-1995 多次迁移/迁出/迁入
  - 1989-12-12 新生儿登记
  - 1997-03-15 迁出
  - 2001-03-08 母亲死亡登记
  - 2002-09-12 父亲死亡登记
  - 2008-11-20 奶奶死亡登记
  - **每条带不同年代的户籍本样式**（1970 vs 1990 vs 2000）

### 2.3 渠道 3：第 135 厂
- ❌ 当前：6 份职工档案
- ✅ 应该：**30+ 份**：工资条、考勤、住房分配、入党、调令、退休证明、职工名册

### 2.4 渠道 4：奶奶家遗物
- ❌ 当前：5 件遗物
- ✅ 应该：**50+ 件**：
  - 1989-12-12 北山屯出生证
  - 1990-1996 几十份奶瓶/疫苗本/小学录取通知/成绩单/奖状
  - 1997 火车票
  - 2001 父亲死亡讣告
  - 2002 母亲死亡讣告
  - 2008 奶奶病历 + 死亡证明
  - **每个物件都是一张单独扫描件** + 日期

### 2.5 渠道 5：QQ 群
- ❌ 当前：5 段对话
- ✅ 应该：**30+ 段对话**，从 2006-2010 群创建到当下
  - 2006 群创建
  - 2008 奶奶去世讨论
  - 2009 你考上大学
  - 2010+ 你的后续动态（你不知道的）
  - **含表情包 + 截图 + 表情**
  - **同学 A 给你私聊发图片** = 偷拍北山屯拆迁现场

### 2.6 渠道 6：寻人/失踪公告
- ❌ 当前：4 条
- ✅ 应该：**20+ 条**，含你爷爷一辈的同事、邻居、远亲
  - 1959-1961 相关人员
  - 1989-1991 同期工人
  - 1995 周德厚
  - 2001-2002 你父母辈
  - 2003 北山屯拆迁相关
  - 2008 你奶奶

## 5. 交互/UX（核心差距）

### 5.1 真实感
- ❌ 当前：纯文字
- ✅ 应该：
  - 鼠标悬停有「嘟」声 + 按钮高亮
  - 输入框失焦有「滴」声
  - 加载慢时有「正在加载...」+ 转圈
  - 错误用 Windows 经典黄底感叹号
  - 5 分钟不操作弹「您已离线，是否继续？」

### 5.2 真实登录失败
- ❌ 当前：直接红字
- ✅ 应该：
  - **输错 1 次**：红字提示
  - **输错 2 次**：警告「您已输入错误 2 次。档案馆管理系统将自动记录。」
  - **输错 3 次**：锁定 60 秒 + 屏幕变灰 + 「请联系档案馆前台」

### 5.3 进度感知
- ❌ 当前：顶部显示 0/6
- ✅ 应该：
  - 加载每条记录时有「正在检索...」+ 转圈
  - 检索成功有「滴」声 + 印章
  - 检索失败有「档案不存在」黄底提示
  - 进度条 = XP 风格绿色横条 6 段

### 5.4 存档（学灵异论坛 4 个 LS key）
- ❌ 当前：3 个 key 但只是进度
- ✅ 应该：
  - `na_progress` = { channel1, channel2, ..., evidenceA, choice }
  - `na_evidence` = 6 个证据
  - `na_identity` = 玩家姓名+身份证
  - `na_favorites` = 收藏的关键档案
  - 「已读」/「未读」标记
  - 顶部「上次查档时间」显示

### 5.5 移动端适配
- ❌ 当前：所有页面都是桌面
- ✅ 应该：
  - 移动端隐藏任务栏
  - 档案馆表格用堆叠布局
  - 报纸扫描用 1 列 + 缩放
  - QQ 群聊用单列气泡

## 6. 玩法/剧情（核心差距）

### 6.1 元谜题
- ❌ 当前：5 个密码
- ✅ 应该：
  - **6 个真实语义密码**（已做到）
  - **3 个隐藏元谜题**：
    1. **数字密码隐藏在档案里**（如档案编号 135-00231 暗示 135 厂密码）
    2. **时间谜题**：1995-09-12 与 1989-12-12 暗示「5 年前与 5 年后」
    3. **元数据谜题**：右上角点击「版本号 2009」5 次 = 隐藏彩蛋
  - **1 个真结局** vs **2 个假结局**（藏得很好的假结局 = 选 D/E 看似善终但触发隐藏）
  - **流程：6 渠道 = 100% 真相**（任意 3 渠道 = 70% 真相）= **避免一渠道通关**

### 6.2 二周目内容
- ❌ 当前：4 结局走完就完了
- ✅ 应该：
  - 二周目 = 切换到「1989 年爷爷视角」= 爷爷那一晚到底发生了什么
  - 三周目 = 切换到「2008 年奶奶视角」= 奶奶那封信之前的所有挣扎
  - **4 周目 = 1997 年周德厚视角** = 他在向阳区农贸市场失踪之前发生了什么

### 6.3 彩蛋
- 顶部 logo 点 5 次 = 显示「1995 年向阳区农贸市场卫星地图」
- 报纸页 1989-12-22 会议合影 = 真实拍摄了 12 个「模糊人脸」= 玩家点击 12 个都能看到身份
- 奶奶家遗物 = 87 件（1 件一件都可点），点完所有触发「奶奶生前视频」
